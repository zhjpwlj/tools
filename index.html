Tools Navigation

A centralized hub for accessing various web development tools. Easily add, edit, or remove tools from the navigation.

How to Edit Navigation Items

  1. To add a new tool, simply add a new object to the toolsData array in the data.js file.
  2. To remove a tool, delete its object from the toolsData array.
  3. To edit a tool, modify its properties in the toolsData array.
  4. Each tool object should have: id, title, description, link, and icon properties.

Example tool object:

{
  id: 3,
  title: "New Tool",
  description: "Description of the new tool.",
  link: "new-tool.html",
  icon: "fas fa-toolbox"
}
